# 🤖 AI Landing Page

A modern and responsive landing page for an AI-powered product built using **React.js** and **Vite**. This project demonstrates component-based development, responsive design principles, and a clean UI design system without backend integration.

## 📌 Project Overview

This project was developed as part of a **Full Stack Internship frontend assessment**. The objective was to create a responsive AI product landing page using a modern frontend framework while following UI/UX best practices and a component-based architecture.

The landing page includes:

- Responsive Navigation Bar
- Hero Section
- Features Section
- Pricing Section
- Contact Section
- Footer

The application is fully responsive and optimized for mobile, tablet, and desktop devices.

---

## 🚀 Framework Choice

This project uses **React.js** with **Vite**.

### Why React.js?

- Component-based architecture
- Reusable UI components
- Better scalability
- Improved code organization
- Widely used industry-standard frontend library

### Why Vite?

- Fast development server
- Instant Hot Module Replacement (HMR)
- Optimized production builds
- Modern and lightweight tooling

## 🧩 Component Structure

### Navbar
Provides responsive navigation links and allows users to quickly access different sections of the landing page.

### Hero
Displays the main product message, description, and primary call-to-action buttons.

### Features
Highlights the main AI product features and benefits.

### Pricing
Displays available pricing plans using a clean card-based layout.

### Contact
Provides contact information and user interaction options.

### Footer
Contains copyright information and additional navigation links.

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/UBAID0704/PromptFlow-AI-Landing-Page-.git
```

### Navigate to Project Folder

```bash
cd PromptFlow-AI-Landing-Page-
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open the application in your browser:

```
http://localhost:5173
```
